Privacy Policy

Effective Date: April 2026

This Chrome Extension is designed to assist users in filling form fields using voice input. Your privacy is important to us. This extension operates entirely within your browser and does not collect or transmit personal data.

1. Information We Collect

This extension does not collect, store, or share any personal information. Specifically, we do not collect:

  • Personally identifiable information (name, email, address, etc.)
  • Health-related information
  • Financial or payment information
  • Authentication credentials
  • Browsing history
  • User activity tracking data

2. Local Processing

All voice recognition and form-filling functionality is processed locally within the user's browser. No data is sent to external servers or third-party services.

3. Permissions Usage

This extension uses only the minimum permissions required:

  • activeTab – to interact with the current webpage when the user activates the extension
  • storage – to save user preferences locally in the browser
  • host permissions – to detect and fill form fields when the user initiates voice input

These permissions are used strictly for the core functionality of the extension.

4. Third-Party Services

This extension does not use any external APIs, remote scripts, or third-party services. All functionality is bundled within the extension package.

5. Data Sharing

We do not sell, trade, or transfer any user data to third parties.

6. Security

Since no user data is collected or transmitted, risks related to data exposure are minimized.

7. Changes to This Privacy Policy

If this privacy policy changes in the future, updates will be posted on this page.
